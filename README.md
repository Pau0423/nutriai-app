🥗 NutriAI - Generador de Menús con IA
📌 Descripción

NutriAI es una aplicación web desarrollada con Streamlit que permite generar menús alimenticios personalizados según diferentes tipos de dieta.

La aplicación simula el comportamiento de un sistema de inteligencia artificial mediante lógica condicional, adaptando los resultados según las preferencias y restricciones ingresadas por el usuario.

🎯 Objetivo

Brindar una herramienta simple e interactiva que ayude a las personas a planificar su alimentación según necesidades específicas como:

Dieta gástrica
Dieta astringente
Dieta diabética
Dieta vegetariana
⚙️ Funcionalidades

✔ Selección de tipo de dieta
✔ Ingreso de preferencias (ej: sin pollo, sin arroz, vegetariano)
✔ Generación automática de menú
✔ Adaptación dinámica según restricciones
✔ Interfaz web interactiva

🧠 ¿Cómo funciona?
El usuario selecciona un tipo de dieta
Ingresa preferencias o restricciones alimentarias
Presiona el botón "Generar menú"
La aplicación procesa la información
Se genera un menú personalizado
🚀 Tecnologías utilizadas
Python 🐍
Streamlit 🌐
Lógica condicional (simulación de IA)

🧾 Prompt inicial

“Generar un menú diario adaptado a una dieta específica considerando restricciones alimentarias indicadas por el usuario.”

⚠️ Uso de IA y API

Para el desarrollo de la aplicación no se utilizó una API Key de inteligencia artificial debido a las limitaciones de facturación requeridas por el servicio.

En su lugar, se implementó una lógica condicional que simula el comportamiento de un modelo de IA, permitiendo adaptar dinámicamente los resultados en función de las preferencias y restricciones ingresadas por el usuario.

Esta decisión permitió cumplir con los objetivos del proyecto, demostrando la comprensión del uso de prompts, la estructuración de la lógica de respuesta y la integración dentro de una aplicación web funcional.

Asimismo, la aplicación se encuentra preparada para integrar fácilmente una API de inteligencia artificial en futuras versiones, lo que permitiría escalar la solución sin modificaciones estructurales significativas.

💰 Factibilidad económica

La aplicación presenta una alta factibilidad económica, ya que:

No utiliza APIs pagas
No requiere infraestructura compleja
Puede escalarse fácilmente
Es de bajo costo de mantenimiento
📌 Conclusión

NutriAI demuestra cómo se pueden aplicar conceptos de inteligencia artificial para resolver problemas cotidianos, ofreciendo una solución accesible, adaptable y fácil de usar para la planificación alimentaria.
